# MIXIT STUDIO

이미지와 문구를 조합해 밈, 카드, SNS 게시용 이미지를 만드는 브라우저 편집 도구입니다. 편집 결과를 실시간으로 확인하고 PNG 또는 JPEG 파일로 내려받을 수 있습니다.

## 빠른 안내

**어디로 가나요?**: [MIXIT STUDIO 열기](https://aleph-task-03.vercel.app)

**무엇을 하나요?**

1. 이미지 탭에서 PNG·JPEG 이미지를 추가하거나 텍스트 탭을 선택한 뒤 카드 위를 클릭해 문구를 입력합니다.
2. 요소의 위치·크기·스타일과 레이어 순서를 조절하고, 배경과 카드 비율을 선택해 미리보기를 확인합니다.
3. 완성한 카드를 PNG·JPEG로 저장합니다. 다시 편집할 작업은 템플릿으로 저장하고 JSON으로 백업할 수 있습니다.

**무엇이 보이면 통과?**: 편집한 이미지와 문구가 미리보기에 반영되고, 내려받은 파일에 선택 테두리 없이 표시되면 됩니다. 템플릿은 저장 후 새로고침해도 목록에 남아야 하며, 불러오면 저장 당시 내용이 복원되어야 합니다.

**안 될 때**: 화면의 오류 안내를 먼저 확인하세요. 이미지는 파일당 15MB 이하의 PNG·JPEG인지 확인하고, JSON은 이 도구에서 내보낸 백업 파일을 사용하세요. 저장 공간 부족 시 이미지 용량을 줄이세요. 새로고침하기 전에는 현재 작업을 템플릿으로 저장하고 중요한 템플릿을 JSON으로 백업하세요.

## 주요 기능

- **여러 이미지 편집**: 이미지 추가, 드래그 이동, 크기 조절, 회전, 좌우·상하 대칭을 지원합니다. 위치·크기·회전은 슬라이더와 숫자 입력으로 조정할 수 있습니다.
- **여러 문구 편집**: 카드 위 직접 입력, 한글·영문·줄바꿈·이모지 입력, 글꼴·글자 크기·색·정렬·위치 변경을 지원합니다. 텍스트 상자의 너비에 맞춰 자동 줄바꿈하며 높이는 내용에 맞게 조정됩니다.
- **레이어 관리**: 작업 공간의 전체 레이어 목록에서 이미지와 문구의 겹침 순서를 함께 관리합니다. 화살표 또는 드래그로 순서를 바꿀 수 있습니다.
- **배경 선택**: 기본 배경 12종과 투명 배경, 사용자 배경 이미지 불러오기를 지원합니다. 배경은 일반 편집 요소와 분리되어 있습니다.
- **실시간 미리보기 및 내보내기**: 편집 내용을 즉시 확인하고 선택 표시를 제외한 결과를 PNG·JPEG로 저장합니다.
- **템플릿 관리**: 여러 템플릿의 저장·불러오기·업데이트·삭제와 썸네일 표시를 지원합니다.
- **JSON 백업 및 복원**: 템플릿 전체를 파일로 내보내고 복원합니다. JSON 구문, 필수 데이터, 중복 ID, 포함된 이미지의 읽기 가능 여부를 검사한 뒤 저장합니다.

## 사용 방법

### 이미지와 문구 편집

1. 왼쪽 **이미지** 탭의 **이미지 추가**를 누르거나 추가 영역에 파일을 끌어 놓습니다. 여러 파일을 함께 선택할 수 있습니다.
2. **텍스트** 탭을 누른 뒤 카드의 원하는 위치를 클릭하면 문구를 입력할 수 있습니다.
3. 기존 문구를 한 번 클릭하면 이동·크기 조절을 위한 선택 상태가 됩니다. 선택된 문구를 다시 클릭하면 내용을 수정할 수 있습니다.
4. 문구의 너비 조절 핸들과 회전 핸들, 선택 항목의 편집 설정을 사용합니다. 이미지도 카드 위 핸들로 크기를 조절할 수 있습니다.
5. **배경 선택**과 비율 버튼으로 카드 구성을 정합니다. 비율 변경은 요소의 상대 위치를 기준으로 반영되므로, 저장 전 각 비율에서 배치와 줄바꿈을 확인하세요.

### 출력 크기

| 비율 | 저장 이미지 크기 |
| --- | --- |
| 1:1 | 1080 × 1080 px |
| 4:5 | 1080 × 1350 px |
| 9:16 | 1080 × 1920 px |

투명 배경이 필요하면 **PNG로 저장**을 선택하세요. JPEG는 투명도를 지원하지 않습니다. 브라우저 창 크기와 화면 확대율은 미리보기 크기에 영향을 주지만 출력 해상도는 위 표를 따릅니다.

### 템플릿과 백업

1. 이름을 입력하고 **템플릿 저장**을 누릅니다.
2. **불러오기**는 해당 템플릿을 현재 작업으로 엽니다.
3. **업데이트**는 해당 템플릿을 현재 작업 내용으로 덮어씁니다.
4. **JSON 내보내기**로 전체 템플릿을 백업합니다.
5. **JSON 가져오기**로 백업을 복원합니다.

> JSON 가져오기는 기존 목록에 추가하는 방식이 아니라 **템플릿 목록 전체를 교체**합니다. 가져오기 전에 기존 목록을 백업하세요. 유효한 빈 목록을 가져오면 저장된 목록도 비게 됩니다. 복원된 템플릿은 목록에서 불러와 편집할 수 있습니다.

템플릿은 같은 브라우저·프로필·사이트 주소의 저장 공간에 보관됩니다. IndexedDB를 우선 사용하고 사용할 수 없으면 localStorage를 사용합니다. 다른 기기나 브라우저로 자동 동기화되지 않으며, 사이트 데이터 삭제 시 사라질 수 있습니다. **저장하지 않은 현재 작업은 새로고침 이후 복원이 보장되지 않습니다.**

### 단축키

| 단축키 | 동작 |
| --- | --- |
| Delete | 선택 요소 삭제 |
| Ctrl + C / X / V | 선택 요소 복사 / 잘라내기 / 붙여넣기 |
| Ctrl + Z | 실행 취소 |
| Ctrl + Y 또는 Ctrl + Shift + Z | 다시 실행 |
| Esc | 카드 위 문구 입력 종료 |

macOS에서는 Ctrl 대신 Command도 사용할 수 있습니다. 입력창에서 타이핑 중에는 요소용 단축키 대신 기본 입력 동작이 적용됩니다. 편집 이력은 최대 40개이며 새로고침 후 유지되지 않습니다.

## 파일 처리와 주의 사항

- 이미지 파일은 PNG·JPEG만 지원하며 파일당 최대 15MB입니다. 지원하지 않는 형식이나 초과 파일은 이유를 표시하고 제외합니다. 여러 파일 중 정상 파일은 추가될 수 있습니다.
- 추가한 이미지는 브라우저에서 디코딩 후 Canvas로 다시 인코딩합니다. 원본 EXIF·GPS 등의 메타데이터를 그대로 복사하지 않습니다. JPEG는 재압축되므로 원본 바이트와 동일하지 않습니다.
- JSON 구문이나 데이터가 잘못되거나 포함된 이미지를 읽을 수 없으면 복원을 중단하고 기존 작업과 템플릿을 유지합니다.
- 글꼴은 Google Fonts에서 불러옵니다. 네트워크 상태에 따라 대체 글꼴이 표시될 수 있으므로 저장 전 글꼴과 줄바꿈을 확인하세요.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 이미지가 추가되지 않음 | PNG·JPEG 형식, 15MB 제한, 파일 손상 여부와 오류 안내 확인 |
| 템플릿 저장 실패 | 이미지 해상도·용량을 줄이고 브라우저 저장 공간 확인. 삭제 전 JSON 백업 |
| 템플릿 목록이 보이지 않음 | 저장했던 브라우저·프로필·주소인지 확인. 다른 환경에서는 JSON 백업 가져오기 |
| JSON 복원 실패 | 이 도구에서 내보낸 파일인지 확인. 구문·필수 필드·중복 ID·이미지 손상 오류 안내 확인 |
| 문구 편집 또는 단축키가 안 됨 | 요소 선택 여부 확인. 문구는 선택 후 다시 클릭해 입력하고, 요소 단축키는 입력창 밖에서 사용 |
| 글꼴이나 줄바꿈이 다름 | 인터넷 연결과 글꼴 로딩 상태 확인 후 미리보기 재확인 |
| 투명 배경이 유지되지 않음 | 투명 배경을 선택하고 JPEG 대신 PNG로 저장 |
| 다운로드 파일을 찾을 수 없음 | 브라우저 다운로드 목록·저장 폴더·다운로드 차단 여부 확인 |

## 로컬 실행

별도의 프레임워크 빌드 없이 `index.html`, `styles.css`, `app.js`를 제공하는 정적 사이트입니다. 프로젝트 폴더를 로컬 정적 서버로 열어 사용하세요. 예를 들어 VS Code의 Live Server에서 `index.html`을 열 수 있습니다.

외부 글꼴을 제외한 주요 편집 로직은 브라우저의 HTML Canvas와 JavaScript로 동작합니다.

## 테스트

Node.js가 설치된 환경에서 프로젝트 폴더를 기준으로 실행합니다.

```sh
node --check app.js
node --test tests/template-import.test.cjs
```
